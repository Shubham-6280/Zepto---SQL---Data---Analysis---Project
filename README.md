# 🛒 Zepto SQL Data Analysis

A SQL-based data analysis project that explores Zepto's product dataset to uncover valuable business insights. This project demonstrates SQL skills through data cleaning, exploratory data analysis (EDA), and business-focused queries related to pricing, discounts, inventory, and revenue.

---

## 📌 Project Objectives

- Explore and understand the dataset
- Clean and prepare the data for analysis
- Analyze pricing and discount trends
- Identify inventory insights
- Generate category-wise business reports
- Practice real-world SQL querying techniques

---

## 📂 Dataset

The dataset contains product information from Zepto, including:

- Product ID
- Product Name
- Category
- MRP
- Discount Percentage
- Discounted Selling Price
- Available Quantity
- Product Weight
- Stock Status

## 📊 Business Questions Solved

- Total number of products available
- List of unique product categories
- Products with the highest discounts
- Premium products currently out of stock
- Category-wise estimated revenue
- Categories offering the highest average discount
- Best value products based on price per gram
- Product classification based on weight
- Total inventory weight by category
